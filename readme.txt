Sets a custom category-tab order for Divi Filterable Portfolio modules.

== Installation ==
1. Upload and activate the plugin.
2. Edit the Divi Filterable Portfolio module.
3. Under Advanced > CSS ID & Classes, add this CSS class: rhiannon-portfolio
4. Go to Settings > Divi Portfolio Tabs.
5. Adjust the order if needed and save.

The default order is:
user-experience
product-management
software-development
graphic-design

The All tab always remains first. Any category not listed in Settings stays after the listed categories.
